# 接口文档

## 用户认证

### 登录

用户登录系统，获取访问令牌。

**请求信息**

| 项目 | 内容 |
|------|------|
| URL | `/user_manage/user_login/user_login_web` |
| Method | `POST` |
| Content-Type | `application/json` |

**请求参数**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| username | string | 是 | 用户名 |
| password | string | 是 | 密码 |

**请求示例**

```json
{
    "username": "admin",
    "password": "123456"
}
```

**响应参数**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | int | 状态码，200成功，401失败 |
| message | string | 提示信息 |
| data | object | 返回数据 |
| data.token | string | 访问令牌 |
| data.user | object | 用户信息 |
| data.user.id | int | 用户ID |
| data.user.username | string | 用户名 |
| data.user.role | string | 角色代码 |
| data.user.role_name | string | 角色名称 |
| data.user.prison_id | string | 所属监狱ID |
| data.user.prison_name | string | 所属监狱名称 |

**成功响应示例**

```json
{
    "code": 200,
    "message": "登录成功",
    "data": {
        "token": "token_1_admin",
        "user": {
            "id": 1,
            "username": "admin",
            "role": "admin",
            "role_name": "管理员",
            "prison_id": "",
            "prison_name": ""
        }
    }
}
```

**失败响应示例 - 用户名或密码错误**

```json
{
    "code": 401,
    "message": "用户名或密码错误",
    "data": null
}
```

**失败响应示例 - 参数错误**

```json
{
    "code": 400,
    "message": "参数错误",
    "data": {
        "username": ["该字段是必填项。"],
        "password": ["该字段是必填项。"]
    }
}
```
