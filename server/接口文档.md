# 接口文档

## 用户认证

### 登录

用户登录系统，获取访问令牌。

**请求信息**

| 项目 | 内容 |
|------|------|
| URL | `/user_manage/user_login/user_login_web/` |
| Method | `POST` |
| Content-Type | `application/json` |

**请求参数**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| username | string | 是 | 用户名 |
| password | string | 是 | 密码 |

**请求示例**

```json
{
    "username": "admin",
    "password": "admin123"
}
```

**响应参数**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | int | 状态码，200成功，401失败 |
| message | string | 提示信息 |
| data | object | 返回数据 |
| data.token | string | 访问令牌 |
| data.id | int | 用户ID |
| data.username | string | 用户名 |
| data.role | string | 角色代码 |
| data.role_name | string | 角色名称 |
| data.prison_id | string | 所属监狱ID |
| data.prison_name | string | 所属监狱名称 |

**成功响应示例**

```json
{
    "code": 200,
    "message": "登录成功",
    "data": {
        "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
        "id": 1,
        "username": "admin",
        "role": "admin",
        "role_name": "管理员",
        "prison_id": "",
        "prison_name": ""
    }
}
```

**失败响应示例 - 用户名或密码错误**

```json
{
    "code": 401,
    "message": "用户名或密码错误",
    "data": null
}
```

## 账号管理

> 注意：账号管理接口需要携带登录获取的 token 进行访问。
> 请求头需要添加: `Authorization: Bearer {token}`

### 账号列表

获取所有子账号列表（管理员专用）。

**请求信息**

| 项目 | 内容 |
|------|------|
| URL | `/user_manage/account/account_list/` |
| Method | `GET` |
| Authorization | `Bearer {token}` |

**响应参数**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | int | 状态码，200成功，403无权限 |
| message | string | 提示信息 |
| data | array | 账号列表 |
| data[].id | int | 账号ID |
| data[].username | string | 账号 |
| data[].name | string | 姓名 |
| data[].role | string | 角色代码 |
| data[].role_name | string | 角色名称 |
| data[].prison_id | string | 所属监狱ID |
| data[].prison_name | string | 所属监狱名称 |
| data[].status | string | 账号状态 |
| num | int | 账号数量 |

**成功响应示例**

```json
{
    "code": 200,
    "message": "success",
    "data": [
        {
            "id": 2,
            "username": "operator1",
            "name": "操作员1",
            "role": "operator",
            "role_name": "操作员",
            "prison_id": "001",
            "prison_name": "第一分监区",
            "status": "active"
        },
        {
            "id": 3,
            "username": "manager1",
            "name": "经理1",
            "role": "manager",
            "role_name": "经理",
            "prison_id": "001",
            "prison_name": "第一分监区",
            "status": "active"
        }
    ],
    "num": 2
}
```

**失败响应示例 - 无权限**

```json
{
    "code": 403,
    "message": "无权限访问",
    "data": null
}
```

### 新增账号

新增子账号（管理员专用）。

**请求信息**

| 项目 | 内容 |
|------|------|
| URL | `/user_manage/account/account_add/` |
| Method | `POST` |
| Authorization | `Bearer {token}` |

**请求参数**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| username | string | 是 | 账号 |
| password | string | 否 | 密码（默认123456） |
| name | string | 否 | 姓名 |
| role | string | 否 | 角色（默认operator） |
| prison_id | string | 否 | 所属监狱ID |
| prison_name | string | 否 | 所属监狱名称 |

**请求示例**

```json
{
    "username": "operator2",
    "password": "123456",
    "name": "操作员2",
    "role": "operator",
    "prison_id": "002",
    "prison_name": "第二分监区"
}
```

**响应参数**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | int | 状态码，200成功，400失败 |
| message | string | 提示信息 |
| data | object | 新增的账号信息 |

**成功响应示例**

```json
{
    "code": 200,
    "message": "新增成功",
    "data": {
        "id": 4,
        "username": "operator2",
        "name": "操作员2",
        "role": "operator",
        "role_name": "操作员",
        "prison_id": "002",
        "prison_name": "第二分监区"
    }
}
```

**失败响应示例 - 账号已存在**

```json
{
    "code": 400,
    "message": "账号已存在",
    "data": null
}
```

**失败响应示例 - 无权限**

```json
{
    "code": 403,
    "message": "无权限访问",
    "data": null
}
```

### 删除账号

删除子账号（管理员专用，不能删除admin账号）。

**请求信息**

| 项目 | 内容 |
|------|------|
| URL | `/user_manage/account/account_delete/` |
| Method | `POST` |
| Authorization | `Bearer {token}` |

**请求参数**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | int | 是 | 要删除的账号ID |

**请求示例**

```json
{
    "id": 2
}
```

**响应参数**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | int | 状态码，200成功，400/404失败 |
| message | string | 提示信息 |
| data | null | 无 |

**成功响应示例**

```json
{
    "code": 200,
    "message": "删除成功",
    "data": null
}
```

**失败响应示例 - 不能删除管理员**

```json
{
    "code": 400,
    "message": "不能删除管理员账号",
    "data": null
}
```

**失败响应示例 - 账号不存在**

```json
{
    "code": 404,
    "message": "账号不存在",
    "data": null
}
```
